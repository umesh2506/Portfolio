# **App Name**: Profolio

## Core Features:

- External Links Hub: Consolidate and display links to various professional platforms (GitHub, LinkedIn, personal website).
- Resume Display: Display an uploaded resume in a visually appealing format.
- Resume Editing Tool: Allow users to make simple edits (like changing font and spacing; other parameters TBD) to their displayed resume, by prompting an AI tool to output changes in formatting.
- Project Gallery: Showcase created website projects with images, descriptions, and links.
- Contact Form: Enable visitors to send messages directly to the portfolio owner.

## Style Guidelines:

- Primary color: Charcoal (#333333) for a professional feel.
- Background color: Off-white (#FAFAFA) to ensure readability and a clean aesthetic.
- Accent color: Teal (#008080) for highlights and interactive elements; adds a touch of sophistication.
- Body and headline font: 'Inter', a sans-serif typeface, provides a modern, neutral and very readable appearance.
- Use simple, line-based icons for navigation and key actions.
- Emphasize a clean, minimalist layout with generous spacing.
- Subtle transitions and hover effects for a polished user experience.
